# Documentation

This section compiles the project specifications, architectural decisions, and regulatory definitions established across **Milestone 1 (Inception)**, **Milestone 2 (Elaboration)**, and **Milestone 3 (Construction)**.

- **[Personas](./personas.md):** Target actors, goals, workflows, and context (Team Manager, Developer, and Open-Source Software User).
- **[State of the Art](./state-of-the-art.md):** Comparison with existing tools, problem statement, core frameworks (STRIDE, LINDDUN, DFDs), and RepoPrint advantage.
- **[Use Cases](./use-cases.md):** Comprehensive use cases (UC01 to UC11) and the **MVP Scope & Delivery Phasing** defined for the Construction phase.
- **[Requirements](./requirements.md):** Functional (23 FRs) and Non-Functional Requirements (19 NFRs), updated with GDPR data erasure, local AI privacy, and accessibility specifications.
- **[Architecture](./architecture.md):** System architecture, backend pipeline, interaction flows, technology stack, database schema, and security/privacy encryption layers.
- **[UI Mockups](./mockups.md):** Static mockups for the web platform, extension, and audit reports, revised with **Milestone 3 UI improvements** and **WCAG accessibility enhancements**.
- **[Legal & Compliance](./compliance.md):** Complete regulatory framework covering GDPR data protection, EU AI Act Article 50 transparency, Portuguese Cybercrime Law, dependency license audit, and platform terms of service.
